# Project Setup

## 1. Clone the Repository

```bash
git clone https://github.com/Krishacde/project-sem-5.git
cd project-sem-5
```

## 2. Get the Latest Changes (Before You Start Working)

```bash
git pull origin main
```

## 3. Backend Setup

```bash
cd backend
npm install
npm run dev
```

**Backend:** http://localhost:5000

## 4. Frontend Setup

Open a new terminal:

```bash
cd frontend
npm install
npm run dev
```

**Frontend:** http://localhost:5173

## 5. Before Pushing Your Changes

Always pull the latest changes first:

```bash
git pull origin main
```

Then push your changes:

```bash
git add .
git commit -m "Your commit message"
git push origin main
```
